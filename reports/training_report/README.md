# تقرير البرنامج التدريبي ومشروع Voice of Customer

تقرير عربي مختصر من ٨ شرائح لغير المتخصصين، بتصميم مستلهم من التقرير المرجعي المرفق: خلفية فاتحة وشريط أخضر وبطاقات ملخص. استُخدم المرفق للتنسيق فقط، ولم يُنقل محتواه أو أسماء جهاته أو الأشخاص الواردين فيه.

- [البوربوينت القابل للتعديل](Voice_of_Customer_Training_Report.pptx)
- [نسخة PDF للقراءة](Voice_of_Customer_Training_Report.pdf)

يتناول التقرير البرنامج التدريبي، وفكرة المشروع، وطريقة العمل، وأمثلة المدخلات والمخرجات، والبيانات والنتائج، والفوائد والحدود والتطوير القادم. النصوص والأشكال قابلة للتحرير داخل PowerPoint، وتتضمن الشرائح ملاحظات للمتحدثة تشرح المصادر والتفاصيل.

## مصادر المعلومات

- خطة البرنامج: https://github.com/SDAIAAcademy/applied-nlp
- بيانات المشروع: `../../DATA_CARD.md` و`../../PROJECT_SUMMARY.json`.
- المقارنة: `../metrics.json`؛ Macro-F1 = 0.533 للأساسي و0.575 للمحسن، على 66 تعليقًا ثابتًا.
- اختبارات البرنامج: `../test_validation.json`؛ 22 اختبارًا ناجحًا، وهي لا تعني صحة كل التنبؤات.
- تحليل الأخطاء: `../error_analysis.csv`؛ 28 خطأ تنبؤ فعليًا.

البيانات مؤلفة تعليمية وليست تعليقات عملاء حقيقيين، والتحسن محدود. لا يدعي التقرير تنفيذ fine-tuning أو جاهزية الاستخدام التشغيلي أو اعتمادًا رسميًا أو إتمام العرض أمام المدرب.
