# Data

`feedback.csv`: 198 original synthetic teaching examples, MIT licensed. No downloads or customer credentials needed. All source rows, labels and splits are version-controlled. See the root `DATA_CARD.md` for annotation definitions, exact split counts, provenance, privacy and limitations. No real customer dataset is bundled or claimed.

Uploaded CSVs for the demo should contain one `text` column only. Never add private customer records to this repository.
